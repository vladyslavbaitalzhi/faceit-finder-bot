# Faceit Finder Bot

Telegram-бот на Python, который по ссылке на Steam-профиль показывает
статистику игрока на Faceit по CS2.

> **Статус проекта:** основной сценарий работает — бот принимает ссылку на
> Steam-профиль, находит игрока Faceit и отправляет статистику CS2 с
> inline-кнопками профиля и обновления.

## Стек

- Python 3.11+
- aiogram 3 (long polling)
- httpx (асинхронные HTTP-запросы)
- pydantic-settings (конфигурация из `.env`)

## Запуск

### 1. Создать виртуальное окружение

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

Для запуска тестов установите dev-зависимости:

```bash
pip install -r requirements-dev.txt
```

### 3. Настроить окружение

Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

Linux/macOS:

```bash
cp .env.example .env
```

Заполните параметры:

| Переменная | Обязательность | Описание |
|---|---|---|
| `BOT_TOKEN` | Да | Токен бота от [@BotFather](https://t.me/BotFather) |
| `STEAM_API_KEY` | Для коротких ссылок и Steam-статистики | Ключ Steam Web API для ссылок `/id/...`, vanity-имён, часов CS2 и VAC-статуса |
| `FACEIT_API_KEY` | Для статистики | Ключ Faceit Data API v4 |

`BOT_TOKEN` обязателен для запуска бота. Прямые ссылки
`/profiles/<SteamID64>` и голый SteamID64 разрешаются без `STEAM_API_KEY`.
Без `FACEIT_API_KEY` бот запускается, но на ссылки отвечает сообщением о
ненастроенной проверке Faceit.

### 4. Запустить бота

Из корня проекта:

```bash
python -m bot.main
```

Бот запустится в режиме long polling. Для остановки нажмите `Ctrl+C`.

## Что умеет бот

- `/start` — приветствие и краткая инструкция.
- `/help` — справка по использованию.
- Любое сообщение со ссылкой на Steam-профиль:
  - `/profiles/<SteamID64>` или голый SteamID64;
  - `/id/<vanity>` или голое vanity-имя (нужен `STEAM_API_KEY`).
- Если у игрока нет аккаунта Faceit с CS2, бот отвечает:
  `У этого игрока нет Faceit-аккаунта с CS2`.
- Сообщение со статистикой содержит:
  - шапку: ник, флаг страны, уровень и текущий ELO, максимальный ELO
    (если API его отдаёт) и ссылку на профиль;
  - место в рейтинге страны и региона Faceit;
  - общую статистику: матчи, винрейт, K/D, HS%, лучшую и текущую серию;
    рядом с винрейтом и K/D показано значение за последние 20 матчей
    со стрелкой ↑/↓;
  - форму за последние 20 матчей: средние K/D, ADR, K/R, килы, винрейт
    и результаты последних 10 матчей (новые слева);
  - последние 5 матчей: карта, счёт, K/D/A и изменение ELO;
  - таблицу всех карт пула с винрейтом и числом матчей, отсортированную
    по винрейту. Карты с 30+ матчами помечаются как лучшие (🏆) или
    слабые (📉) относительно общего винрейта, остальные — ▫️, карты
    с меньшей выборкой — значком ⚠️;
  - Steam: часы в CS2 и статус VAC-бана (при наличии `STEAM_API_KEY`
    и открытом профиле);
  - время обновления внизу сообщения.
- Отсутствующие в ответе API поля и блоки просто пропускаются, сообщение
  обрезается до лимита Telegram в 4096 символов.
- Inline-кнопки:
  - «Открыть профиль на Faceit»;
  - «Обновить» — сбрасывает кэш Faceit и заново загружает статистику.

`FaceitClient` кэширует ответы на 5 минут, повторяет запросы при 429/5xx и
закрывается при остановке приложения. Один экземпляр клиента создаётся в
`bot/main.py` и передаётся хендлерам через `Dispatcher`.

## Тесты

Из корня проекта:

```bash
pytest
```

Тесты не выполняют реальных сетевых запросов: HTTP-клиент замокан.

## Возможные доработки

1. Хранить историю матчей и строить графики прогресса.
2. Добавить сравнение двух игроков.
3. Кэшировать профили в базе данных и поддержать несколько игр Faceit.
